# Prompt revision — 2026-10-31

Checked all 34,249 entries (33,935 characters and 314 styles) with explicit text rules. Changed 5,641 reusable captions and prepared 33,785 revised full-scene prompts. Styles remain unchanged. Fixed three malformed copy-file references.

The revised full-scene prompt uses neutral whole-character framing instead of listing ears, a tail tip and feet. Selected tied-hairstyle tags are written explicitly as hair descriptions. A human-species label is removed only where the supplied appearance explicitly identifies an android or robot; gender is retained. Real anatomical tails, names, series and source tags are preserved.

**Images were not regenerated or curated.** Original generation_prompt values, workflow JSONs and image metadata remain historical records. The new reuse_generation_prompt is for future generation. In the detail panel, “Copy revised generation prompt” copies the complete revised text; replace the whole Positive prompt with it. “Open original generation workflow” downloads the historical workflow, which still contains the original wording.

This is a wording/data-consistency repair, not a guarantee of character accuracy or fewer unwanted tails. No controlled GPU comparison was performed. Missing or ambiguous source attributes remain flagged rather than guessed. 15,946 records have at least one review flag, which does not by itself mean the record is incorrect.

Included in the Release ZIP under this folder: `revised-prompts.csv` (all revised prompts) and `review-needed.csv` (source attributes needing review).

Verified all record/sidecar/API values and unchanged SHA256 for all 102,747 image, workflow and source-tag files. Browser checks covered search, images, reusable-prompt copying and revised-generation-prompt copying in the actual local application and public demo.

The refreshed v0.1.2 Release ZIP, maintainer's distribution copy and full Hugging Face demo include this revision. The 120-image GitHub Pages sample remains a separate historical preview. Existing workflows retain the original wording; use the revised-generation copy button for the corrected full prompt. Older archives are retained as before-prompt-revision.
